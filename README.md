# FF6PR Save Editor

### 🎮 [Open the tool](https://0utrider.github.io/ff6pr-save-editor/)

A browser-based save editor for *Final Fantasy VI Pixel Remaster*. Runs entirely client-side — no
backend, no account, and your save file never leaves your device.

Build status, development setup, and the save format spec: [ProjectInfo.md](ProjectInfo.md).

Prefer a downloadable Windows client instead? The original
[AnotherFFVIPRSaveEditor](https://github.com/GiulioSamp/AnotherFFVIPRSaveEditor) (C#/WinForms) offers
one.
